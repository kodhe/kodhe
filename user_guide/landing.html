Kodhe Framework User Guide

This is the bilingual landing page of the user guide. The full table of contents
is maintained per language — one README/index file inside each language folder:

  • 🇬🇧 English: en/index.md
  • 🇮🇩 Bahasa Indonesia: id/index.md

Halaman ini adalah pengantar dua bahasa dari user guide. Daftar isi lengkap dikelola
per bahasa — satu berkas README/daftar isi di dalam tiap folder bahasa:

  • 🇬🇧 Inggris: en/index.md
  • 🇮🇩 Bahasa Indonesia: id/index.md

Language Structure / Struktur Bahasa

This user guide consists of two language folders, each containing a full guide
— including its own table-of-contents page (<lang>/index.md, the "README" of that
language) — in its own language:

User guide ini terdiri dari dua folder bahasa, masing-masing berisi panduan
lengkap — termasuk halaman daftar isi sendiri (<lang>/index.md, "README"-nya
bahasa tersebut) — sesuai bahasanya:

FolderLanguagePer-language TOC fileContents
en/🇬🇧 Englishen/index.mdconcepts/, general/, libraries/ — fully translated ✅
id/🇮🇩 Bahasa Indonesiaid/index.mdconcepts/, general/, libraries/
FolderBahasaBerkas daftar isi per bahasaIsi
en/🇬🇧 Inggrisen/index.mdconcepts/, general/, libraries/
id/🇮🇩 Bahasa Indonesiaid/index.mdconcepts/, general/, libraries/ — penuh

Open the README inside the language folder you want; that README carries the full
table of contents for that language. In the HTML site built by
scripts/build_user_guide.py, each <lang>/index.md becomes <lang>/index.html
with an ID · EN switcher in the header.

Buka README di dalam folder bahasa yang Anda inginkan; README itulah yang memuat
daftar isi lengkap untuk bahasa tersebut. Di situs HTML hasil
scripts/build_user_guide.py, setiap <lang>/index.md menjadi <lang>/index.html
dengan pemilih ID · EN di header.

The path structure of both folders is identical (e.g. id/libraries/session.md ↔
en/libraries/session.md), so cross-language links are always available.

Struktur path kedua folder identik (mis. id/libraries/session.md ↔
en/libraries/session.md), sehingga tautan silang antar-bahasa selalu tersedia.

Main difference vs CI3: every library is a separate Composer package with the
namespace Kodhe\Framework\<Paket>\*. Install only the packages you need;
there is no more mandatory $this->load->library() for every feature.

Perbedaan utama dengan CI3: setiap library adalah paket Composer terpisah dengan
namespace Kodhe\Framework\<Paket>\*. Anda cukup memasang paket yang dibutuhkan;
tidak ada lagi $this->load->library() wajib untuk semua fitur.

Documentation Source Hierarchy / Hierarki Sumber Dokumentasi

  1. user_guide/<lang>/index.md — per-language table of contents & learning narrative (en/ English, id/ Bahasa Indonesia). Daftar isi & narasi pembelajaran per bahasa.
  2. user_guide/<lang>/<subfolder>/*.md — the actual guide pages, one folder per language. Halaman panduan sebenarnya, satu folder per bahasa.
  3. <package>/README.md — canonical per-package API reference (always the most current). Referensi API kanonik per paket (selalu paling mutakhir).
  4. doc/ — historical archive, deprecated, do not use as a reference. Arsip historis, deprecated, jangan dijadikan rujukan.

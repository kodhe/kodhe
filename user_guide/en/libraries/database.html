Database

Package: kodhe/database (+ kodhe/driver as the driver abstraction).

Connection

use Kodhe\Framework\Database\Connection;

$conn = Connection::factory([
    'drivername' => 'Mysqli',            // or 'Pdo'
    'hostname'   => 'localhost',
    'username'   => 'app',
    'password'   => 'secret',
    'database'   => 'myapp',
]);

Query Builder (CI3 style)

$rows = $conn->select('id, title')->from('posts')
             ->where('status', 'publish')
             ->order_by('created', 'desc')
             ->limit(10, 0)
             ->get()->result_array();

The Mysqli driver validates identifiers safely (the null guard has been fixed —
there is no longer a strcspn() TypeError on empty input).

Namespace Migration (CI3 → Kodhe Framework)

This page is the name reference map. For the complete step-by-step migration
procedure (installation, bootstrap, config, verification checklist, rollback), see
Migrating from CodeIgniter 3.

There are three namespace generations. Modern application code only needs to know the
third one.

GenerationExampleStatus
Original CI3CI_Session, $this->load->library('session')Still works via loader aliases
Legacy KodheKodhe\Session\Session, Kodhe\Library\*Obsolete — not autoloaded, never write it in new code
Active (PSR-4)Kodhe\Framework\Session\DatabaseDriver etc.✅ Standard across all packages

Rules for writing new code

  1. Always use Kodhe\Framework\<Package>\<Class>; — never write Kodhe\Library\* or Kodhe\<Package>\<Class> (without Framework).
  2. Do not rely on CI_* aliases; they are only a safety net for legacy code.
  3. If Class "Kodhe\<X>\<Y>" not found appears: the legacy class is not autoloaded — switch to the FQCN in the table above and run composer dump-autoload.

Small API changes during migration

Some methods were normalised to camelCase, e.g. Email: reply_to() → replyTo(),
set_mailtype() replaced by a config option; DB sessions use the new CI3 schema column
(timestamp, not lastactivity — the gc fallback still supports the old one).
Always check the package README for the final signature.

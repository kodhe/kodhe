Kodhe Framework User Guide

Documentation for application development on top of the Kodhe Framework,
organized following the CodeIgniter 3 User Guide
structure — general topics, per-package library reference, and linked index
pages in every sub-folder. This folder (en/) is the full English version;
the Indonesian version lives in ../id/index.md.

Structure by Language

This user guide consists of two language folders, each containing a full guide
in its own language:

FolderLanguageContents
en/🇬🇧 Englishconcepts/, general/, libraries/ — fully translated ✅
../id/index.md🇮🇩 Bahasa Indonesiaconcepts/, general/, libraries/

The path structure of both folders is identical (e.g. id/libraries/session.md ↔
en/libraries/session.md), so cross-language links are always available in the HTML
site built by scripts/build_user_guide.py (ID · EN switcher in the header).

Main difference vs CI3: every library is a separate Composer package with the
namespace Kodhe\Framework\<Paket>\*. Install only the packages you need;
there is no more mandatory $this->load->library() for every feature.
